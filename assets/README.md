# Public Product Assets

This directory is reserved for public product screenshots and approved brand imagery used by the SENTARYN showcase.

Suggested filenames:

- `authority-map.png` — visualization of requested, authorized, and actual scope
- `authority-decision.png` — example authority decision surface
- `change-passport.png` — public Change Passport view
- `shadow-mode.png` — non-blocking Shadow Mode result
- `hero.png` — repository or website hero artwork
- `logo.png` — approved SENTARYN logo asset

Only assets cleared for public distribution should be stored here. Screenshots must not expose credentials, secrets, customer data, private policy schemas, internal deployment details, proprietary Governor internals, or other private implementation information.

These image files are documented placeholders and are not included until approved public assets are available.
